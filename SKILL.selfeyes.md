# Selfeyes Skill

Selfeyes is a static photography gallery at **https://thoughtrights.com/selfeyes/**
combined with a local-only ingestion pipeline that discovers, detects, scores,
and curates portrait photographs from public-domain and CC-licensed sources.

## Gallery architecture

### Manifest-driven loading
The gallery has **no hardcoded images**. `script.js` fetches `manifest.json` and
builds all DOM nodes from it. Adding an image means adding an entry to
`manifest.json` — no HTML changes needed.

### manifest.json format
```json
{
  "items": [
    {
      "src":  "assets/pipeline/flickr-12345_left_face.jpg",
      "zoom": "assets/pipeline/flickr-12345_left_eye.jpg",
      "alt":  "",
      "w": 800, "h": 1050,
      "id":   "flickr-12345-left",
      "attribution": {
        "photographer": "Jane Doe",
        "source_url":   "https://flickr.com/photos/...",
        "license":      "CC BY 2.0",
        "license_url":  "https://creativecommons.org/licenses/by/2.0/"
      }
    }
  ]
}
```

Key fields:
- `src` — gallery thumbnail (face crop, path relative to `html/`)
- `zoom` — tap-to-zoom target (eye crop)
- `w`, `h` — pixel dimensions of `src`; used to reserve space before load (prevents reflow)
- `id` — globally unique; pipeline items follow `<source>-<photo_id>-<side>`
- `attribution` — required for CC license compliance; shown in future lightbox overlay

### Lazy loading + layout stability
- `IntersectionObserver` with `rootMargin: '300px'` defers image requests until
  near-viewport
- All 383 DOM nodes are built in a `DocumentFragment` and added in a **single**
  `gallery.appendChild(frag)` call — prevents browser painting one item at a time
- `img.style.aspectRatio = w + ' / ' + h` ensures every item has correct height
  before its image loads — prevents CSS column rebalancing as images arrive
- Do **not** revert to `img.src` at build time or use `animationDelay` on items

### Tap-to-zoom lightbox
- Click gallery item → opens `#modal` showing `src` (face crop)
- Tap/click image in modal → zoom to `scale(3) translate(...)` centered on tap point
- Second tap → instant snap back (`resetZoom()`)
- `resetZoom()` must be called in `openModal`, `goTo`, AND `closeModal` — failing
  to reset transform causes next-opened image to appear clipped
- Zoom target image (eye crop) is not used in current lightbox; reserved for
  future attribution overlay feature

## Pipeline architecture

### What is automated vs. manual

| Step | Automated | Human |
|---|---|---|
| Source search (Flickr/LoC/Smithsonian) | ✓ | |
| Metadata + license filter | ✓ | |
| Download + SHA dedup | ✓ | |
| mediapipe Face Mesh detection | ✓ | |
| Eye-size + sharpness filter | ✓ | |
| Reflection score (specular ratio × contrast) | ✓ ranks | |
| Face crop + eye crop generation | ✓ | |
| Perceptual hash (pHash) for similarity | ✓ | |
| **Approve / skip** — is this a good reflection? | | ✓ review UI |
| Promote approved → manifest.json | ✓ | |

### Python environment
```bash
cd pipeline
python3.9 -m venv .venv          # mediapipe requires 3.9–3.12; does NOT support 3.13
source .venv/bin/activate
pip install -e .
```

### Full command reference
```bash
# Discover candidates from all sources (no download)
python -m selfeyes_pipeline discover
python -m selfeyes_pipeline discover --source flickr
python -m selfeyes_pipeline discover --source loc
python -m selfeyes_pipeline discover --source smithsonian
python -m selfeyes_pipeline discover --source flickr --max-pages 5

# Download, detect faces/eyes, score, crop
python -m selfeyes_pipeline process
python -m selfeyes_pipeline process --source flickr
python -m selfeyes_pipeline process --limit 50          # test batch
python -m selfeyes_pipeline process --reprocess         # re-detect already-downloaded

# Discover + process in one shot
python -m selfeyes_pipeline run
python -m selfeyes_pipeline run --source flickr --max-pages 2 --limit 100

# Launch Flask review UI at http://localhost:5050
python -m selfeyes_pipeline review
python -m selfeyes_pipeline review --port 5051

# Sync all approved items → html/manifest.json (headless, no UI needed)
python -m selfeyes_pipeline export

# Print candidate/eye/review counts
python -m selfeyes_pipeline stats

# Compute/update perceptual hashes for all existing crops
python -m selfeyes_pipeline rehash

# Backup the database with a timestamp
python -m selfeyes_pipeline backup
```

### Typical workflow
```bash
# 1. Discover new candidates
python -m selfeyes_pipeline discover

# 2. Process a test batch to check quality
python -m selfeyes_pipeline process --limit 50

# 3. Review in the UI
python -m selfeyes_pipeline review    # http://localhost:5050

# 4. Full process run (hours — leave it running)
python -m selfeyes_pipeline process

# 5. Backup DB before any major change
python -m selfeyes_pipeline backup

# 6. Review duplicates: Duplicates tab in review UI
# 7. Export approved items to manifest.json
python -m selfeyes_pipeline export

# 8. Deploy
cd .. && ./deploy.sh
```

### Database (SQLite)
- Location: `pipeline/data/manifest.sqlite`
- Three tables: `candidates` → `eyes` → `review`
- **Never edit the DB directly** for review status; use the Flask UI or
  `store.set_review_status()`
- Schema migrations are idempotent ALTER TABLE statements in `Store._init()`
- Backups land in `pipeline/data/manifest-backup-YYYYMMDD-HHMMSS.sqlite`
- The `.sqlite` file is gitignored; never commit it

### Reflection scoring
- Eye crop converted to grayscale
- Iris zone = center 50% ellipse of eye bbox
- `specular_ratio` = pixels with luma > 220 / iris zone area
- `local_contrast` = std dev of luma in iris zone (normalised)
- `reflection_score` = specular_ratio × local_contrast
- Higher = more likely to contain a visible scene reflection in the iris
- Score is a ranking signal, not a hard filter — use it to prioritise review order

## Deploy

```bash
./deploy.sh              # build check + rsync to thoughtrights:docroot/selfeyes
./deploy.sh --dry-run    # preview what would be transferred
```

**This is an rsync deploy, not git pull.** The live server receives files directly.
`deploy.sh` runs a build check first:
1. Validates `manifest.json` is well-formed JSON
2. Verifies all `src` paths in manifest exist on disk
3. Runs rsync with `--delete` (removes files from server that no longer exist locally)

After deploy: **always run `./deploy.sh` from the repo root**, not from `html/`.

When manifest.json changes, always update `w`/`h` for new items:
```bash
pipeline/.venv/bin/python -c "
import json; from pathlib import Path; from PIL import Image
m = json.load(open('html/manifest.json'))
for item in m['items']:
    if 'w' not in item:
        p = Path('html') / item['src']
        with Image.open(p) as img: item['w'], item['h'] = img.size
json.dump(m, open('html/manifest.json','w'), indent=2)
"
```

## Hard constraints

1. **No facial recognition** — mediapipe Face Mesh returns landmark geometry only.
   No embeddings, no identity matching, no similarity scoring across people.
   The `phash` similarity is on crop *images*, not on faces.

2. **Permissive licenses only** — CC BY, CC BY-SA, CC0, Public Domain, U.S. Gov.
   No CC ND, no CC NC unless `allow_non_commercial = true` in config.

3. **Attribution required** — every pipeline-sourced gallery item must have all
   four attribution fields populated before export.

4. **No minors, no AI images** — enforced by tag blocklist in `config.toml`.
   See `references/selfeyes-sources.md` for blocklist rationale.

5. **Photos only** — `content_type=1` on Flickr; tag blocklist catches illustration/
   painting/rendering on other sources.
